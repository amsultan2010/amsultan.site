# Contributing

This is a personal site, so the design and the content are mine to decide. Fixes are welcome: bugs, broken links, typos, accessibility and performance problems.

- For anything bigger than a small fix, open an issue first so we can agree on it before you write code.
- Run `npm run check` before opening a pull request; it must build.
- Keep a pull request to one change, with lowercase imperative commit messages (`fix rail drag on touch`).
- Page text stays lowercase.

By contributing you agree that your contribution is licensed under the [MIT license](LICENSE).
