# abdullah sultan — portfolio

Static, motion-led portfolio built with:

- **HTML**, **CSS**, and vanilla **JavaScript**
- **GSAP** + ScrollTrigger
- **Vite** for local development and production builds

Live: [www.abdullahmsultan.me](https://www.abdullahmsultan.me)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
