# abdullah sultan — portfolio

Static portfolio built with the same stack as [wodniack.dev](https://wodniack.dev):

- **Astro** (static)
- **SCSS** + Autoprefixer + modern-normalize
- **GSAP** + ScrollTrigger
- **Lenis** smooth scroll

Live: [www.abdullahmsultan.me](https://www.abdullahmsultan.me)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
