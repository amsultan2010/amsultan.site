# Font licenses

Self-hosted for amsultan.site. None of these files is covered by the repository MIT license.

## Geist Serif

Geist Serif Regular (`geist-serif-regular.woff2`), from the Vercel `geist` package 1.9.0. SIL Open Font License 1.1. Full text: `OFL-geist.txt`. The release is one weight. Display type requests a heavier weight and the face file paints this regular cut, so the page never synthesizes a bold.

## Host Grotesk

Host Grotesk Light (`host-grotesk-light.woff2`) by Ivo Gabrowitsch, The Foundry Types, and contributors. SIL Open Font License 1.1. Full text: `OFL-host-grotesk.txt`. The site uses the light cut, the thinnest weight the family ships, everywhere a mono label used to be.

## Cabinet Grotesk and Satoshi

Cabinet Grotesk (`cabinet-grotesk-variable.woff2`) and Satoshi (`satoshi-variable.woff2`) are from Fontshare, designed by Indian Type Foundry, under the ITF Free Font License 2.0. Full text: `FFL.txt`.

Self-hosting on this site is the use that license allows. The files are not a font download for anyone else. A third party gets their own copy from [fontshare.com](https://www.fontshare.com/). Cabinet Grotesk is the z combinator wordmark. Satoshi is the downforce wordmark.
