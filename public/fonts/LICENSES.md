# Font licenses

Self-hosted for abdullahsultan.tech. None of these files is covered by the repository MIT license.

## Geist Serif

Geist Serif Regular (`geist-serif-regular.woff2`), from the Vercel `geist` package 1.9.0. SIL Open Font License 1.1. Full text: `OFL-geist.txt`. The release is one weight. Display type requests a heavier weight and the face file paints this regular cut, so the page never synthesizes a bold.

## Host Grotesk

Host Grotesk Light (`host-grotesk-light.woff2`) and the medium italic (`host-grotesk-500-italic.woff2`) by Ivo Gabrowitsch, The Foundry Types, and contributors. SIL Open Font License 1.1. Full text: `OFL-host-grotesk.txt`. The site uses the light cut everywhere a mono label used to be. The italic is only the word sultan.

Caveat (`caveat-500.woff2`) and Instrument Serif italic (`instrument-serif-italic.woff2`) are SIL Open Font License 1.1 faces, used only while sultan redraws. Caveat is by Pablo Impallari. Instrument Serif is by Rodrigo Fuenzalida.

The same redraw also uses Playfair Display italic (`playfair-display-italic.woff2`, Claus Eggers Sorensen), IBM Plex Mono (`ibm-plex-mono.woff2`, Mike Abbink), Great Vibes (`great-vibes.woff2`, Robert Leuschke), and Syne (`syne-700.woff2`, Bonjour Monde). Each is SIL Open Font License 1.1, subset to the letters in sultan.

## Cabinet Grotesk and Satoshi

Cabinet Grotesk (`cabinet-grotesk-variable.woff2`) and Satoshi (`satoshi-variable.woff2`) are from Fontshare, designed by Indian Type Foundry, under the ITF Free Font License 2.0. Full text: `FFL.txt`.

Self-hosting on this site is the use that license allows. The files are not a font download for anyone else. A third party gets their own copy from [fontshare.com](https://www.fontshare.com/). Cabinet Grotesk is the z combinator wordmark. Satoshi is the downforce wordmark.
