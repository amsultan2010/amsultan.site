# Security

If you find a security problem in this site or its code, please report it privately through [GitHub's vulnerability reporting](https://github.com/amsultan2010/amsultan.site/security/advisories/new) instead of opening a public issue.

Only the version deployed at [www.amsultan.site](https://www.amsultan.site) (the `main` branch) is supported.
